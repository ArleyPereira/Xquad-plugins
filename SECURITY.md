# Segurança / Security

Encontrou uma vulnerabilidade nos plugins do Xquad ou no servidor MCP (`https://xquad.app/api/mcp`)? Escreva para **contact@xquad.app** com o assunto "Segurança". Não abra uma issue pública. Respondemos em até 5 dias úteis.

Found a vulnerability in the Xquad plugins or the MCP server? Email **contact@xquad.app** with the subject "Security". Please do not open a public issue. We reply within 5 business days.
